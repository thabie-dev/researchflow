# ResearchFlow

ResearchFlow is a React and FastAPI research workspace with persistent projects, stage version history, downloadable PDF reports, document cosine-similarity analysis, automated Open-Access PDF harvesting, and intelligent NLP keyword extraction.

The comparer supports both a focused two-document result and a bulk journal matrix. Upload 2-30 journal documents to generate an interactive Plotly heatmap, inspect pairwise scores, zoom, and export the visualization as PNG. The bulk pipeline uses BERTopic with `all-MiniLM-L6-v2` embeddings and c-TF-IDF to return clean collection-wide topics and ranked topics for every journal. 

## How The App Works

ResearchFlow is split into a React frontend and a FastAPI backend.

1. The frontend handles uploads, comparison screens, report views, stage selection, and interactive pipeline drag-and-drop zones.
2. The backend receives the uploaded files, stores text and workflow stages in SQLite, and runs similarity, web scraping, and topic-analysis jobs.
3. Each stage is saved in the database so the current state and previous versions remain available.
4. Rolling back a stage is transactional: the current state is saved first, then the selected version is restored.
5. Comparison results are rendered in an interactive Plotly heatmap for bulk journal analysis.
6. PDF and Word (.docx) reports are generated by FastAPI and downloaded directly from the application.

## Setup

**1. System Requirements**
Python **3.12** is required. Make sure to check the "Add Python.exe to PATH" box if you are installing Python for the first time.

**2. Install Dependencies**
Open PowerShell as an Administrator (if required by your system execution policies), navigate to your project folder, and run the following to create your virtual environment and install the dependencies:
```powershell
# Setup Python Backend
cd backend
python -m venv venv
.\venv\Scripts\activate
python -m pip install -r requirements.txt
cd ..

# Setup Node Frontend
npm install

```

**3. Environment Variables**
To use the GitHub Tool Scout without hitting severe rate limits, create a `.env` file in the `backend\` directory. You can create this via File Explorer or by running `notepad backend\.env` in PowerShell.

Add the following content:

```text
# backend/.env
GITHUB_TOKEN=ghp_your_personal_access_token_here

```

**4. Model Caching**
The first BERTopic comparison downloads the `all-MiniLM-L6-v2` transformer model. Later comparisons reuse the local model cache. To prepare the model explicitly before starting the API, ensure your virtual environment is active and run:

```powershell
python backend\scripts\cache_topic_model.py

```

The running API loads the cached model in offline mode, so comparisons do not depend on an internet connection.

## Run

**Option A: The Automated Launcher (Recommended)**
Simply double-click the `start-researchflow.bat` file in your project folder. The launcher checks that Python, npm, and the installed dependencies are available before automatically opening dedicated backend and frontend terminal windows.

**Option B: Manual Start**
If you prefer to start the servers manually, open a PowerShell window and run:

```powershell
npm run dev

```

*(Note: If you run the backend Python server completely manually outside of the `npm run dev` concurrently setup, always remember to run `.\venv\Scripts\activate` in your `backend` folder before starting Uvicorn).*

**Database:** The SQLite database is created automatically at `backend\data\researchflow.db`. Set `RESEARCHFLOW_DATABASE_PATH` in your `.env` to use a different path.

Every stage is persisted in SQLite. Saving a version adds it to the selectable version history (up to 25 snapshots). Rolling back is transactional: ResearchFlow first saves the current draft as a safety version, then restores the selected version, so a rollback can itself be undone.

PDF and Word files are generated by FastAPI and downloaded directly from the export dialog; browser print-to-PDF is not required.

## Verify

Run these commands in PowerShell to verify your installation (ensure your virtual environment is active for the backend tests):

```powershell
python -m pytest backend\tests
npm run lint -w frontend
npm run build -w frontend

```

FastAPI's interactive API documentation is available at `http://127.0.0.1:5000/docs` while the backend is running.
